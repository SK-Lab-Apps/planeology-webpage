# Planeology website: content review

The fact log for this site. The app's own facts are checked in `../Planeology/CONTENT_REVIEW.md` and are reused here as verified. **This file logs every site-only fact**: a number, date or record that appears on the website but not in the app's lessons, quizzes or Hangar cards, with the source it was checked against.

**Status:** ✅ verified against the source · ⚠️ flagged, with what was done about it.

Where good sources disagree, the page says so, and the row lists each figure.

Pages are listed by route. A page with no section below uses only the app's verified facts.
